# SpectraCanvas Demo Video Guide 🎬

**Preparation guide for IBM AI Builders Challenge submission video**

## 📋 Demo Requirements

- **Duration**: 3-5 minutes
- **Format**: MP4, MOV, or WebM
- **Resolution**: 1080p minimum
- **Audio**: Clear narration with no background noise
- **Content**: Show all key features and AI capabilities

### Brand Studio Demo (90 seconds)

## 🎥 Recording Tips

### Setup
1. **Close unnecessary tabs/windows** - Clean desktop
2. **Set browser zoom to 100%** - Consistent sizing
3. **Use incognito/private mode** - Clean browser state
4. **Disable notifications** - No interruptions
5. **Test audio levels** - Clear narration

### Recording Tools
- **OBS Studio** (Free, professional)
- **Loom** (Easy, web-based)
- **QuickTime** (Mac built-in)
- **Windows Game Bar** (Windows built-in)

### Best Practices
- **Speak clearly and confidently**
- **Pause between sections** - Easier to edit
- **Show, don't just tell** - Demonstrate features
- **Keep cursor movements smooth** - Not too fast
- **Highlight key features** - Use cursor to point
- **Practice 2-3 times** - Get comfortable with flow

### Editing
- **Trim dead space** - Keep it tight
- **Add captions** - Accessibility
- **Include background music** - Low volume, non-distracting
- **Add title card** - Project name and your name
- **Add end card** - GitHub link, contact info
